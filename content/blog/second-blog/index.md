> "Sometimes the best tool is the one you build for exactly one user: yourself."

## Introduction

Instead of adopting an off-the-shelf static site generator, I wrote my own. Not because existing tools are bad, but because I wanted to understand every step between a markdown file and a deployed page.

## What It Does

1. **Reads markdown**: Pulls content from a simple folder structure.
2. **Applies templates**: Wraps content in consistent layout and styling.
3. **Outputs static HTML**: Ready to deploy anywhere, no server required.

## What I Learned

Writing the generator taught me more about templating, file I/O, and deployment pipelines than using any pre-built tool ever did.

## Conclusion

It's a small tool, built for a small purpose — but it's mine, and I understand every line of it.
